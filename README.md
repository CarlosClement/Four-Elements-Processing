# Four Elements — interactive Processing sketch

An interactive animation built with Processing, with one animated scene for each of the four elements: earth, water, fire and air.

Solo project made for the course *Introduction à l'informatique graphique* (first year of the LDD Informatique–Mathématiques, Université Paris-Saclay, 2023–2024).

Updated in 2026 for macOS compatibility (Retina displays) and performance.

## What it does

The sketch opens on a title screen. Pressing Enter shows a menu, and each arrow key opens a scene:

| Key | Scene | What you see |
| --- | --- | --- |
| Enter | Menu | List of the available modes |
| Up | Earth | Recursive trees, grass, bushes, clouds and a rising sun |
| Down | Water | Rain made of 250 falling drops |
| Left | Fire | A wildfire of 25 flickering flames with smoke |
| Right | Air | Wind trails flowing across the screen |

The mouse interacts with the scenes: grass bends away from the cursor, and the wind trails are deflected around it.

The on-screen text is in French.

## Techniques used

- **Recursion**: the trees are generated by a recursive function where each branch spawns four smaller branches with random length and angle.
- **Bézier curves**: the raindrops and the layered flames are drawn with `bezierVertex`.
- **Direct pixel access**: the gradient backgrounds are written straight into the `pixels[]` array.
- **Geometric transformations**: `pushMatrix`, `translate`, `scale` and `rotate` are used to reuse one shape (drop, flame, cloud, bush) at many sizes and positions.
- **Particle trails**: the wind is ten arrays of `PVector` positions, shifted every frame and displaced with a sine wave.
- **Controlled randomness**: `random`, `randomSeed` and `noise` give variation while keeping the earth scene stable from frame to frame.

## How to run it

1. Install [Processing](https://processing.org/download).
2. Download this repository and open the `.pde` file in Processing.
3. Make sure the `data` folder (containing `start.vlw` and `modes.vlw`) stays next to the `.pde` file, since the sketch loads its fonts from there.
4. Press Run, then press Enter.

The window is 800 × 800 pixels.

## Note on performance

The earth scene redraws both recursive trees on every frame, so it runs more slowly than the other scenes.
